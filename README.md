# Cybersecurity Walkthroughs 🛡️

A collection of hands-on cybersecurity walkthroughs documenting my journey through practical security labs, challenges, and rooms.

This repository serves as my personal learning journal, where I document the techniques, tools, commands, enumeration processes, vulnerabilities, and lessons learned while solving different cybersecurity challenges.

## 🎯 Objectives

- Develop practical penetration testing skills.
- Improve enumeration and reconnaissance techniques.
- Understand common vulnerabilities and exploitation methods.
- Practice Linux, networking, web security, and privilege escalation.
- Document methodologies and lessons learned.
- Build a reference for future learning and revision.



## 🧰 Tools & Technologies

- Nmap
- Gobuster / Feroxbuster
- Burp Suite
- Netcat
- Metasploit
- Linux command-line tools
- Wireshark

## 📖 Walkthrough Structure

Each walkthrough aims to include:

1. Room overview and objectives
2. Reconnaissance and enumeration
3. Identified vulnerabilities
4. Exploitation methodology
5. Privilege escalation (where applicable)
6. Commands and tools used
7. Key takeaways and lessons learned

## ⚠️ Disclaimer

All content in this repository is intended for educational purposes and ethical cybersecurity learning.

The walkthroughs document my personal learning experience in authorized lab environments. Do not use the techniques described against systems without explicit permission.

## 📈 Progress

This repository will continuously grow as I solve more rooms, learn new techniques, and improve my methodology.

**Learn. Practice. Document. Repeat.**
